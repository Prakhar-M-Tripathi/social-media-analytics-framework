# Hackathon Problem Statement

## Background
Social media platforms are complex ecosystems driven by human emotion, diverse demographics and interconnected networks. To understand an online community, one must look beneath the surface: how followers feel (sentiment analysis), who they are (demographics), what topics captivate them (trend tracking) and how they influence one another (link analysis). Combining these four vectors using AI is the key to true audience intelligence.

## Description
Design and build an AI-driven Social Media Analytics Framework that processes raw platform data to extract deep, actionable audience insights. The system must use AI and machine learning to infer follower sentiment, map audience demographics, identify top trending narratives, and perform link and network analysis to uncover how information and influence flow among followers.

## Expected solution: five components

A. Continuous Data Collection and Timeline Management
A multi-platform ingestion pipeline that pulls live data, posts, user interactions and comments, with a structured, time-stamped historical database that maps the chronology of conversations.
- Essentials: X (formerly Twitter) and Telegram
- Desirable: Instagram and Facebook
- Appreciable additions: Reddit or YouTube (text context from video comments)

B. Multi-Dimensional Sentiment Inference
Use NLP to detect nuanced emotions (sarcasm, anxiety, excitement, supportive, against and so on) in posts and comment threads, and map how sentiment fluctuates along the data timeline.

C. Automated Demographic Profiling
Models that infer aggregate, anonymised follower demographics (age brackets, geographic distribution, language, professional interests) from public profile indicators, bio text and behavioural patterns.

D. Real-Time Trend and Topic Detection
Automatically identify, rank and predict rising trends, viral keywords and shifting discussions as they emerge chronologically in the dataset.

E. Link Analysis and Network Topology
Map relationships among followers, identify nodes of high influence (key opinion leaders), and visualise how a trend or sentiment spreads from one user segment to another over time.
