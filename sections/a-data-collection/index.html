Component A | Data collection and timeline

An X-first feed for campaign intelligence

Configure multiple company campaigns, collect authorized platform content when access is available, and normalize posts and conversation links for the analysis sections.

Demo outputs are synthetic. They simulate campaign posts across six platform labels. No API is called when you open this page or generate the demo.
Primary | X

Public campaign search

The optional X adapter searches configured terms, hashtags, URLs, and public account posts. X read requests may incur charges; collection requires an explicit command, approved access, and a cost acknowledgement.

Optional | Telegram

Authorized chat updates

The Telegram bot adapter reads updates only from configured chats where the bot has access. It cannot search all public Telegram conversations or retrieve arbitrary history.

Prototype | No API calls

Rich synthetic fixtures

Multi-campaign sample conversations include varied text, languages, replies, quotes, repost edges, profile placeholders, mock engagement, and separate expected labels.

How this feed supports the project

Shared analysis input

demo_posts.csv keeps the agreed post columns for sentiment, timeline, topic, and reply analysis. Its timestamps are UTC and replies point to parent posts.

Evidence sidecars

Separate files carry campaign match reasons, source and collection times, source references, available metrics, and typed network edges without changing shared CSV columns.

Clearly separated results

Synthetic and live exports use different filenames. Synthetic expected labels are marked as reference fixtures, never as model results or real audience findings.
